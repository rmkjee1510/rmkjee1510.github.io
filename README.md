# rmkjee1510.github.io

Personal academic website of **Rupam Mukherjee** — M.Tech in Medical Imaging &
Informatics, School of Medical Science & Technology, IIT Kharagpur.

Live at <https://rmkjee1510.github.io>.

## Structure

| File | Purpose |
| --- | --- |
| `index.html` | Home — bio, research interests, education, selected publications, skills, achievements, summer schools |
| `research.html` | Research overview, full publication list, thesis and projects, tooling |
| `others.html` | Experience timeline, certificates, personal interests |
| `style.css` | Whole design system — tokens, layout, components, light/dark themes |
| `site.js` | Theme toggle persistence and scroll-reveal animation |
| `Rupam_Mukherjee_CV.tex` | LaTeX source for the CV |
| `Rupam_Mukherjee_CV.pdf` | Compiled CV, linked from the nav bar |

Static HTML and CSS with no build step — open `index.html` directly, or serve
the folder with `python3 -m http.server` to preview.

## Theming

Colors, spacing, radii, and fonts are CSS custom properties declared on `:root`
in `style.css`, with a dark set under `html[data-theme="dark"]`. Change a value
once there and it propagates across all three pages.

The theme follows the visitor's `prefers-color-scheme` on first visit; the
toggle in the top bar overrides that and persists the choice in `localStorage`.
An inline script in each `<head>` applies the stored theme before first paint so
there is no flash of the wrong background.

## Updating the CV

`Rupam_Mukherjee_CV.tex` is the source of truth. It needs `fontawesome5`, so
compile with a full TeX distribution:

```sh
pdflatex Rupam_Mukherjee_CV.tex
```

Then commit the regenerated `Rupam_Mukherjee_CV.pdf` — the site links to the PDF,
not the source.

## Adding a publication

Copy an existing `.pub-item` block in `research.html`. The entry numbers are
generated by a CSS counter, so no renumbering is needed. Use `<span class="badge">`
for an acceptance and `<span class="badge badge-muted">` for a preprint.

## Notes

External dependencies are Font Awesome 4.7 (icons) and Google Fonts (IBM Plex
Sans, Source Serif 4), both loaded from CDNs. The pages degrade gracefully to
system fonts and blank icon slots if those are unavailable.
